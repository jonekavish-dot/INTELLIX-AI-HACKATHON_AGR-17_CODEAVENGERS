This document catalogues every configuration file, runtime parameter, environment
variable, and deployment manifest utilized throughout the AgriDiff AI ecosystem.

------------------------------------------------------------------------------
1. ENVIRONMENT CONFIGURATION MANIFESTS
------------------------------------------------------------------------------

File: .env.example.txt (Root template)
Purpose: Canonical template defining all runtime variables and placeholders.
Variables:
  • GEMINI_API_KEY
    - Description: Google Gemini API authorization key.
    - Default / Fallback: If omitted or empty, backend seamlessly falls back to
      deterministic rule-based comparison without failing.
    - Required: No (Optional for advanced AI narrative generation).
  • LLM_MODEL
    - Description: Gemini model version identifier.
    - Default: "gemini-1.5-flash"
    - Alternate: "gemini-1.5-pro"
  • LLM_TIMEOUT_SECONDS
    - Description: Network request timeout before triggering deterministic fallback.
    - Default: 30
  • LLM_MAX_CONCURRENT
    - Description: Max concurrent asynchronous API worker calls.
    - Default: 5
  • PORT
    - Description: HTTP server bind port for FastAPI / Uvicorn.
    - Default: 8000 (Dynamically mapped by cloud providers like Render).
  • VITE_API_URL
    - Description: Base URL for Axios HTTP requests from the React frontend.
    - Default: Empty (Uses Vite development proxy to localhost:8000 in dev;
      configured to Render backend URL in Vercel production).

3. FRONTEND CONFIGURATION FILES
------------------------------------------------------------------------------

File: frontend/package.json
Purpose: Node.js package manifests, execution scripts (dev, build, preview), dependencies.
Scripts:
  • "dev": "vite" (Starts dev server at http://localhost:3000)
  • "build": "vite build" (Compiles production assets to frontend/dist/)
  • "preview": "vite preview" (Serves frontend/dist/ locally)

File: frontend/package-lock.json
Purpose: Cryptographically locked dependency tree ensuring bit-for-bit identical installs.
Committed to Git: YES (Mandatory for reproducible CI/CD and production builds).

File: frontend/vite.config.js
Purpose: Vite bundler configuration, React plugin integration, proxy setup.
Settings:
  • server.port: 3000
  • server.proxy: Proxies '/api' -> 'http://localhost:8000' during local development.

File: frontend/vercel.json
Purpose: Single-Page Application (SPA) routing rules for Vercel deployment.
Settings:
  • rewrites: Routes all client URLs to '/index.html' for React Router.

File: frontend/tailwind.config.js & postcss.config.js
Purpose: Tailwind CSS utility configuration, content paths, autoprefixer pipeline.
